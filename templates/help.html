HELP & FAQ

How to use StudentPredict

A quick guide to the app, the fields it asks for, and answers to common questions.

How it works

You enter five details about your recent study habits and performance. A Decision Tree machine-learning model — trained on a small educational dataset — predicts whether the result trend looks like a Pass or Fail, along with a confidence score. Every prediction is saved to your local History page.

Frequently asked questions

Why does it say "Model not found" on the home page?

The prediction model (model.pkl) hasn't been trained yet. Run python train_model.py in your project folder, then restart python app.py.

Is this a real, reliable prediction of my exam result?

No. This is an educational demo trained on a very small, hand-made dataset. Treat the result as a learning exercise in how ML classification works, not as academic advice.

Where is my data stored?

Locally, in a SQLite file called student_predictor.db inside your project folder. Nothing is sent anywhere else.

I got a validation error — why?

Each field has a valid range (see the table above). For example, attendance must be between 0 and 100, and your name can't be empty.

How do I clear my history?

Use the Admin panel to delete individual predictions, or stop the app and delete the student_predictor.db file to reset everything.

The terminal shows a PATH warning during install — is that a problem?

No. Warnings like "script flask.exe is installed in ... which is not on PATH" are harmless as long as you run the app with python app.py rather than typing flask directly.
