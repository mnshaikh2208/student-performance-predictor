🎯 About the Project

Student Performance Predictor collects study and academic indicators, uses a machine-learning classifier to estimate performance, and provides a personal dashboard for tracking progress.

🚀 Key Features

  • Student registration, login and personal dashboard
  • Total study-hour calculation
  • Total, completed and pending assignment tracking
  • Attendance, previous marks and sleep tracking
  • AI/ML performance prediction with confidence
  • Admin panel and CSV export

🛠 Technology Stack

Frontend: HTML, CSS, JavaScript
Backend: Python + Flask
Database: SQLite
Machine Learning: Scikit-learn + Joblib
